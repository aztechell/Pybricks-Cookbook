# Баги

## Странный `ImportError`, хотя файл есть

Иногда Pybricks Code может показать ошибку вида:

```text
ImportError: no module named 'xact_action'
```

При этом файл `xact_action.py` действительно есть в проекте.

### Частая причина

В основном файле может быть случайный мусорный текст, например:

```python
from xact_action import Action

зк

robot = Robot()
```

Для обычного Python строка `зк` выглядит как имя переменной. Но старые версии Pybricks Code могут сломаться еще раньше: редактор пытается найти все `import`, чтобы загрузить нужные `.py` файлы на хаб. Если анализатор кода спотыкается о такую строку, он может не добавить импортируемый файл в запуск.

В итоге настоящая проблема находится в `main.py`, а сообщение выглядит так, будто пропал модуль.

### Что проверить

1. Удали случайные строки, которые не являются кодом или комментарием.
2. Проверь, что имена файлов совпадают с импортами:

```python
from xact_action import Action
```

значит рядом должен быть файл:

```text
xact_action.py
```

3. Для имен файлов и модулей лучше использовать простой стиль:

```text
xact_action.py
xact_robot.py
mission_main.py
```

### Как должно быть

```python
from xact_action import Action

robot = Robot()
```

Если после удаления мусорной строки ошибка изменилась на `NameError`, `SyntaxError` или другую нормальную ошибку Python, значит импорт уже нашелся, и можно чинить реальную проблему в коде.
